## 🚀 Featured Projects

### 📰 Fake News Detection using Machine Learning
A machine learning application that detects whether a news article is **Real** or **Fake** using Natural Language Processing (NLP) techniques. The project includes text preprocessing, TF-IDF vectorization, model training, evaluation, and an intuitive prediction interface.

**Key Features**
- 🧹 Text preprocessing and cleaning
- 📊 TF-IDF feature extraction
- 🤖 Machine Learning classification
- 📈 Performance evaluation using multiple metrics
- 🌐 Interactive prediction interface

**Tech Stack:** Python • Scikit-learn • Pandas • NumPy • NLP • TF-IDF • Flask

---

### 🏥 Breast Cancer Prediction
A machine learning model that predicts whether a breast tumor is **Benign** or **Malignant** based on diagnostic features. The project focuses on accurate classification to assist in early breast cancer diagnosis.

**Key Features**
- 📊 Data preprocessing and visualization
- 🔍 Feature engineering and selection
- 🤖 Multiple classification models
- 📈 Model evaluation and comparison
- 📉 Performance metrics visualization

**Tech Stack:** Python • Scikit-learn • Pandas • NumPy • Matplotlib • Seaborn

---

### 📊 TOPSIS Python Package
A Python implementation of the **Technique for Order Preference by Similarity to Ideal Solution (TOPSIS)** algorithm for Multi-Criteria Decision Making (MCDM). The package ranks alternatives based on weighted criteria and is published for easy integration into Python projects.

**Key Features**
- ⚖️ Multi-Criteria Decision Making (MCDM)
- 📈 Weighted normalization of criteria
- 🏆 Alternative ranking based on TOPSIS
- 📦 Packaged as a reusable Python library
- 💻 Command-line interface support

**Tech Stack:** Python • NumPy • Pandas • PyPI • Packaging • CLI
